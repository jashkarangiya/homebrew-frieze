# Security policy

## Supported versions

Only the latest release gets security fixes. Older releases are not patched.

## Reporting a vulnerability

Do not open a public issue for a security problem. Report it privately in one of these ways:

- GitHub Security Advisories: open the repository's **Security** tab and click **Report a vulnerability**, or go to <https://github.com/jashkarangiya/homebrew-frieze/security/advisories/new>.
- Email: jashkarangiya@gmail.com

Include:

- The Frieze version (**Settings › About Frieze**) and the macOS version.
- What the problem is and what an attacker could do with it.
- Steps to reproduce, or a proof of concept.
- Any logs, screenshots or crash reports that help. Remove secrets and personal data first.
- Whether you want to be credited, and under what name.

## What to expect

- A first response within 7 days.
- Updates as the fix progresses, and a note when it ships.
- Credit in the advisory or release notes if you want it.

There is no bug bounty.
